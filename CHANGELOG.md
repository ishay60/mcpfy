# Changelog

This file tracks user-visible changes at the **project** level. Per-package
changelogs are generated by [changesets](https://github.com/changesets/changesets)
under each `packages/*/CHANGELOG.md` and are the authoritative record for
version bumps shipped to npm.

How releases work in this repo:

1. A behavior-change PR includes a [changeset](./.changeset/README.md) describing
   which packages bump and why.
2. When the PR merges to `develop`, the [Release workflow](./.github/workflows/release.yml)
   either opens a "Version Packages" PR (which collapses pending changesets into
   version bumps + per-package CHANGELOG entries) or — if that PR was just merged —
   runs `changeset publish` to push the new versions to npm with provenance.
